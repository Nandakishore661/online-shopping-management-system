# Online Shopping Management System

## About the Project
The Online Shopping Management System is a menu-driven Python application developed using **Object-Oriented Programming (OOP)** and **File Handling**.

It allows users to manage products, add products to a shopping cart, calculate bills, and maintain order details using text files.

## Features
- Add new products
- View all available products
- Search products by ID
- Update product details
- Delete products
- Add products to cart
- View cart and calculate total amount
- Generate shopping bills
- Update product stock automatically
- Store product and order details in text files

## Technologies Used
- Python
- Object-Oriented Programming (OOP)
- File Handling
- Text Files (`.txt`)

## How to Run

1. Clone the repository:
```bash
git clone https://github.com/your-username/online-shopping-management-system.git
```

2. Open the project folder:
```bash
cd online-shopping-management-system
```

3. Run the Python file:
```bash
python main.py
```
